# 安全与权限

- **读取**：只读取用户配置的项目根目录与允许清单中的 Codex 主目录。认证存储、浏览器状态、数据库和接收账本不得进入传输内容。
- **写入与删除**：只在明确目标下创建带版本的本地快照、接收状态或恢复副本；不同内容不得静默覆盖。清理只能处理本次操作创建、经过所有权和边界验证的暂存文件，不能借同步请求删除源项目或其他账号数据。
- **网络与凭据**：GitHub 传输复用本机已经登录的 `gh`，不得读取、导出或写入令牌。仓库、可见性和 Release 身份必须显式提供或配置并重新核验；登录失效时只允许官方交互登录。
- **费用与资源**：大型快照会占用磁盘、带宽、GitHub 配额或付费 LFS 容量；启用新的付费路径或可能明显消耗配额前必须停止并确认。
- **最终确认边界**：盘点和就绪检查保持只读。上传、下载、恢复、覆盖、删除、修改远端 Release 或改变仓库可见性都需要当前明确指令。示例配置不得包含真实账号、设备、仓库或路径值。
